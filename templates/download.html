Download Encryptor CLI Tool

High-security terminal application for file encryption and decryption. Features anti-debugger security, custom FayCipher algorithm, AES-256-GCM, and automatic cloud key synchronization.

Download encryptor.exe (Windows 64-bit)

How to sync CLI application with your web account

  1. Step 1: Run the Terminal Application
    Launch encryptor.exe in your terminal or by double clicking it.
  2. Step 2: Link Your Web Account
    Select the menu option "Sync Account / Login" in the CLI application and enter your web account username/email and password.
  3. Step 3: Encrypt Files & Manage Keys
    Whenever you encrypt a folder or file using the CLI app, your encryption key and algorithm details will instantly be sent to your Web Key Vault. You can edit, replace, generate, or delete these keys anytime from this website!
